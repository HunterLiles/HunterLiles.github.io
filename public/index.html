RENDERING RESEARCH

In progress

Signed Distance Field Research

Exploring the benefits and limitations of rendering geometry defined by distance functions.

As an undergraduate researcher, I develop a custom SDF rendering engine with C++, Raylib, and GLSL, including shaders for the distance functions.

  • Raylib provides the application foundation while custom GLSL shaders define the rendered surfaces.
  • The supplied captures show gyroid and repeating-surface experiments with adjustable camera and rendering parameters.
  • These are visual experiments; comparative benchmarks and a detailed contribution breakdown are still to come.

In progress

Blossom

A small, data-oriented Vulkan sandbox for experimenting with rendering and development tools.

  • The Vulkan branch uses GLFW, Dear ImGui, and HLSL shaders.
  • Shader reload keeps the current pipelines active if a replacement is invalid, preserving a working render while iterating.
  • Project browsing and embedded Neovim are implemented. Script attachments exist; native script compilation and reload are still planned.
